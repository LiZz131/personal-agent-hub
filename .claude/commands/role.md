---
description: 切换当前会话的工作角色（整理 / 问答 / 学习规划 / 导师）；不带参数则列出角色和当前角色
argument-hint: "[整理|问答|规划|导师|默认]"
---

用户请求切换角色，参数：`$ARGUMENTS`

角色定义在 `.claude/roles/` 下：

| 参数（任一触发词即可） | 文件 |
|---|---|
| 整理 / 入库 / librarian | `.claude/roles/librarian.md` |
| 问答 / 问 / qa | `.claude/roles/qa.md` |
| 学习规划 / 规划 / 待学 / planner | `.claude/roles/planner.md` |
| 导师 / 检验 / tutor | `.claude/roles/tutor.md` |
| 默认 / 自动 / off | 回到默认：按 CLAUDE.md 自动路由 |

处理方式：
- **参数为空**：列出上面这些角色，每个一句话说明，并告诉我当前会话处于哪个角色（没有切换过就是「默认」）。
- **参数匹配某个角色**：读对应的角色文件。从现在起，到本会话结束或我再次使用 `/role` 为止，严格按该角色工作。CLAUDE.md 的全部约定仍然有效，而且优先于角色文件。回复一行确认：`已切换到「<角色>」：<一句话职责>`，再按角色文件的要求给出开场（导师角色要先问我这次学的是什么）。
- **参数不匹配**：列出可用角色，请我重新选择。
